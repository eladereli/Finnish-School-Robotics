# Finnish-School-Robotics
Robotics and RGB LEDs

# What is Robotics?

Robotics is the study of designing, building, and programming robots. It helps us create machines that can perform different tasks.

# What is an RGB LED?

An RGB LED is a light that can show different colours by mixing red, green, and blue light.

# What does RGB stand for?

RGB stands for:

* R – Red
* G – Green
* B – Blue

# How can we change RGB LED colours on mBot2 using Python?

We can use Python code to control the RGB LEDs. We can choose different values for red, green, and blue to create different colours.

# What happens when we turn off all RGB LEDs?

The LEDs stop shining and the lights become dark.
